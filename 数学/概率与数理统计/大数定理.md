大数定理描述**大量随机变量的算术平均值依概率收敛于期望**，是频率稳定性的理论基础。

## 切比雪夫不等式

设 $X$ 的期望 $E(X)=\mu$，方差 $D(X)=\sigma^2$，则对任意 $\varepsilon > 0$：

$$P\{|X-\mu| \geq \varepsilon\} \leq \frac{\sigma^2}{\varepsilon^2}$$

等价形式：

$$P\{|X-\mu| < \varepsilon\} \geq 1 - \frac{\sigma^2}{\varepsilon^2}$$

> **核心用途**：在只知期望和方差时估计概率上下界，也是证明切比雪夫大数定律的工具。

## 三种大数定律

| 定律           | 条件                                                   | 结论                                                           | 考研重点       |
| ------------ | ---------------------------------------------------- | ------------------------------------------------------------ | ---------- |
| **切比雪夫大数定律** | $X_1,\dots,X_n$ **两两不相关**，方差**一致有界**（$D(X_i)\leq C$） | $\frac{1}{n}\sum X_i \xrightarrow{P} \frac{1}{n}\sum E(X_i)$ | 条件绕口，选填常考  |
| **辛钦大数定律**   | $X_i$ **独立同分布**，$E(X_i)=\mu$ 存在                      | $\frac{1}{n}\sum X_i \xrightarrow{P} \mu$                    | 最常用，条件最简洁  |
| **伯努利大数定律**  | $n_A \sim B(n,p)$（$n$ 重伯努利试验中 $A$ 发生次数）              | $\frac{n_A}{n} \xrightarrow{P} p$                            | 频率→概率的理论依据 |

> **关键区分**：切比雪夫需要「方差存在且一致有界」；辛钦只需要「期望存在」；伯努利是辛钦的特殊情形（二项分布）。

## 依概率收敛

称序列 $\{Y_n\}$ 依概率收敛于 $a$，记为 $Y_n \xrightarrow{P} a$，若：

$$\forall \varepsilon > 0,\quad \lim_{n\to\infty} P\{|Y_n - a| < \varepsilon\} = 1$$

等价表述：$\lim_{n\to\infty} P\{|Y_n - a| \geq \varepsilon\} = 0$。

> **考研常考**：已知 $X_n \xrightarrow{P} a$，$Y_n \xrightarrow{P} b$，证明 $X_n \pm Y_n \xrightarrow{P} a\pm b$ 等运算性质。

## 依概率收敛的运算性质

若 $X_n \xrightarrow{P} a$，$Y_n \xrightarrow{P} b$，$g$ 在 $a$ 处连续，则：

- $X_n \pm Y_n \xrightarrow{P} a \pm b$
- $X_n Y_n \xrightarrow{P} ab$
- $X_n / Y_n \xrightarrow{P} a/b \quad (b \neq 0)$
- $g(X_n) \xrightarrow{P} g(a)$

## 考研记背优先级

- **必背（高频）**：辛钦大数定律（条件+结论）、切比雪夫不等式、依概率收敛定义
- **次级**：切比雪夫大数定律（选填辨析）、伯努利大数定律（含义即可）
- **常考题型**：三大定律的条件辨析（谁需要方差有界？谁需要独立同分布？）、用切比雪夫不等式估计概率

## 切比雪夫大数定律证明思路

由条件 $D(X_i) \leq C$ 及两两不相关：

$$D\left(\frac{1}{n}\sum X_i\right) = \frac{1}{n^2}\sum D(X_i) \leq \frac{nC}{n^2} = \frac{C}{n}$$

代入切比雪夫不等式：

$$P\left\{\left|\frac{1}{n}\sum X_i - \frac{1}{n}\sum E(X_i)\right| \geq \varepsilon\right\} \leq \frac{C}{n\varepsilon^2} \to 0 \quad (n\to\infty)$$

证毕。核心：方差有界 → 样本均值方差 $\to 0$ → 依概率收敛。

## 大数定律 vs 中心极限定理

| | 大数定律 | [[中心极限定理]] |
|---|---|---|
| 研究内容 | 样本均值**收敛到**期望 | 样本均值的**分布形态** |
| 收敛方式 | 依概率收敛 | 依分布收敛 |
| 核心公式 | $\bar{X} \xrightarrow{P} \mu$ | $\frac{\bar{X}-\mu}{\sigma/\sqrt{n}} \xrightarrow{D} N(0,1)$ |
| 直觉 | 「足够多次 → 稳定」 | 「足够多次 → 正态」 |
