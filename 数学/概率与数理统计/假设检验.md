# 假设检验

## 核心思想

**假设检验** (Hypothesis Testing) 是统计推断方法，用于根据样本数据判断关于总体的某个假设是否成立。

核心逻辑是**小概率反证法**：先假定 $H_0$ 成立 → 看样本数据与该假设的相容程度 → 若相容性很差（概率很小），则拒绝 $H_0$。

> [!important] 关键
> 不是直接证明假设成立，而是通过**反证法**推断。类似于法庭上的「无罪推定」。

---

## 基本要素

### 原假设与备择假设

| 假设 | 符号 | 含义 |
|------|------|------|
| **原假设** (Null) | $H_0$ | 通常为"无差异""无效应"，是待检验的对象 |
| **备择假设** (Alternative) | $H_1$ | 与 $H_0$ 对立，是我们希望验证的结论 |

把"无差异"设为 $H_0$ 是保守策略，等价于无罪推定。

### 两类假设（按限定程度）

| 类型 | 定义 | 示例 |
|------|------|------|
| **简单假设** | 完全指定总体分布（唯一确定） | $H_0: \theta = \theta_0$，$H_1: \theta = \theta_1$ |
| **复合假设** | 只部分指定总体分布（不止一种可能） | $H_0: \theta \leq \theta_0$，$H_1: \theta \neq \theta_0$ |

绝大多数实际问题都是复合假设。对于简单 vs 简单情形，[[Neyman-Pearson引理]] 给出了最优势检验（MPT）的构造方法。

### 显著性水平 $\alpha$

事先设定的小概率阈值，常用 $\alpha = 0.05 / 0.01 / 0.10$。

含义：当 $H_0$ 为真时，我们愿意承受的**错误拒绝 $H_0$ 的概率上限**。

### 检验统计量

由样本数据计算出的数值，用来决定是否拒绝 $H_0$。在原假设成立时，其抽样分布是已知的。

| 检验 | 统计量 | 场景 |
|------|--------|------|
| $z$ 检验 | $Z = \frac{\bar{X} - \mu_0}{\sigma / \sqrt{n}}$ | 方差已知，检验均值 |
| $t$ 检验 | $T = \frac{\bar{X} - \mu_0}{s / \sqrt{n}}$ | 方差未知，检验均值 |
| $\chi^2$ 检验 | $\chi^2 = \sum \frac{(O-E)^2}{E}$ | 分类数据、方差检验 |
| $F$ 检验 | $F = \frac{s_1^2}{s_2^2}$ | 两总体方差比较 |

### 拒绝域与临界值

- **拒绝域**：统计量落入即拒绝 $H_0$ 的取值范围
- **临界值**：拒绝域的边界值

```
    拒绝域         接受域         拒绝域
 <---|-------------|-------------|--->
    -z_{α/2}      0          +z_{α/2}
```

## 两类错误与功效

| | $H_0$ 为真 | $H_0$ 为假 |
|---|---|---|
| **拒绝 $H_0$** | **第一类错误** ($\alpha$) | ✅ 正确 |
| **不拒绝 $H_0$** | ✅ 正确 | **第二类错误** ($\beta$) |

> [!danger] 第一类错误（弃真）
> $H_0$ 实际为真，但拒绝了它。概率 = $\alpha$（可控）。

> [!warning] 第二类错误（取伪）
> $H_0$ 实际为假，但没有拒绝它。概率 = $\beta$（通常难以精确控制）。

**$\alpha$ 与 $\beta$ 的权衡**：降低 $\alpha$ 会升高 $\beta$。通常先控制 $\alpha$，再通过增大样本量来减小 $\beta$。

### 检验功效 (Power)

当 $H_0$ 为假时正确拒绝它的概率：$\text{Power} = 1 - \beta$。

**影响因素**：样本量 ↑、效应量 ↑、$\alpha$ ↑、总体方差 ↓ → 功效 ↑

> [!tip] 功效分析
> 研究设计阶段通常要求功效 $\geq 0.80$，以此确定最小样本量。

## 检验步骤

1. **提出假设** → 写出 $H_0$ 和 $H_1$
2. **确定 $\alpha$** → 通常取 $0.05$
3. **选择检验统计量** → $z$ / $t$ / $\chi^2$ / $F$，视数据与条件而定
4. **确定拒绝域** → 根据 $\alpha$ 和分布查临界值
5. **计算统计量值** → 代入样本数据
6. **做出决策** → 比较统计量与临界值，或比较 $p$ 值与 $\alpha$
7. **写出结论** → 用非统计学语言解释

## 双侧检验与单侧检验

| 类型 | 假设形式 | 拒绝域 | 使用条件 |
|------|----------|--------|----------|
| **双侧** | $H_0: \theta = \theta_0$ vs $H_1: \theta \neq \theta_0$ | 两侧 | 只关心是否有差异 |
| **左侧** | $H_0: \theta \geq \theta_0$ vs $H_1: \theta < \theta_0$ | 左侧 | 预期方向为"小于" |
| **右侧** | $H_0: \theta \leq \theta_0$ vs $H_1: \theta > \theta_0$ | 右侧 | 预期方向为"大于" |

单侧检验在同 $\alpha$ 下更容易拒绝，但必须有明确的方向性预期。

## 参数检验 vs 非参数检验

| 维度 | 参数检验 | 非参数检验 |
|------|----------|------------|
| 分布假设 | 需要（通常是正态） | 不需要 |
| 检验对象 | 参数（$\mu$, $\sigma^2$, $p$） | 分布位置、形状 |
| 功效（假设成立时） | **更高** | 略低 |
| 稳健性 | 较低 | **较高** |
| 数据要求 | 定距/定比 | 各类均可 |

### 常见检验对应关系

| 非参数检验 | 参数版对应 | 用途 |
|-----------|-----------|------|
| Wilcoxon 符号秩 | 单样本/配对 $t$ 检验 | 单样本中位数 / 配对比较 |
| Mann-Whitney $U$ | 两独立样本 $t$ 检验 | 两独立样本位置比较 |
| Kruskal-Wallis | 单因素 ANOVA | 多组独立样本比较 |
| Friedman | 随机区组 ANOVA | 多组相关样本比较 |
| Spearman 秩相关 | Pearson 相关 | 相关性检验 |

### 选择指南

| 场景 | 推荐 |
|------|------|
| 数据服从正态分布 | 参数检验（功效更高） |
| 数据严重偏态或有离群值 | 非参数检验 |
| 小样本，无法验证正态性 | 非参数检验（更安全） |
| 定序数据（如 Likert 量表） | 非参数检验 |
| 大样本（中心极限定理适用） | 参数检验（对正态性不敏感） |

## 假设检验与置信区间

两者是同一硬币的两面：

$$
\text{双侧检验在 } \alpha \text{ 水平下拒绝 } H_0: \theta = \theta_0 \quad \Longleftrightarrow \quad \theta_0 \text{ 不在 } 1-\alpha \text{ 置信区间内}
$$

> [!tip] 实用建议
> 置信区间比单纯的"拒绝/不拒绝"提供更丰富的信息。现代统计实践建议**同时报告置信区间和 $p$ 值**。

---

## 常见误区

> [!danger]- 展开查看
> 1. **$p > 0.05$ ≠ $H_0$ 为真** —— 只能说"没有足够证据拒绝 $H_0$"
> 2. **统计显著 ≠ 实际显著** —— 大样本下微小差异也可能显著
> 3. **$p$ 值不是效应量** —— 建议同时报告效应量（Cohen's d 等）
> 4. **不能事后选择假设** —— 假设必须在看到数据之前确定
> 5. **多重比较问题** —— 同时做多个检验会放大第一类错误，需校正（如 Bonferroni）
